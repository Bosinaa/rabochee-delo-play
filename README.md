# РАБОЧЕЕ ДЕЛО — кадровый симулятор

Играть: https://bosinaa.github.io/rabochee-delo-play/

Ты единственный рекрутёр на пять вакансий. Один квартал — шесть недель. Работа идёт по
одной вакансии: берёшь папку и ведёшь её до конца. Каждого кандидата проводишь по воронке
резюме → созвон → тех.скрининг → собес → дебриф → оффер с торгом.

Резюме врут чаще, чем люди: нестыковки видны только при сверке документов между собой.
Слоты инженеров, фонд оплаты и доверие менеджеров общие на все вакансии, а кандидаты
не ждут вечно.

Игра целиком — один HTML-файл, без сервера и без зависимостей. Прогресс хранится в браузере.
Здесь лежит только собранная версия; исходники и пайплайн — в приватном репозитории.
